# Sistema de Gerenciamento de Entrega de Pedidos (C#)

Projeto acadêmico desenvolvido em **C#** com foco na aplicação prática de estruturas de dados lineares (**Lista** e **Fila**) e algoritmos de busca, ordenação e seleção.

## Funcionalidades Implementadas
- **Estruturas Lineares:** Lista para cadastro/gerenciamento geral e Fila (FIFO) para ordem de despacho das entregas.
- **Busca (2 parâmetros):** Por Código do Pedido (ID) e por Nome do Cliente.
- **Ordenação (2 parâmetros):** Por Prioridade de entrega e por Valor do pedido.
- **Seleção/Filtragem (2 parâmetros):** Por Status (Pendente/Em Rota/Entregue) e por Bairro/Prioridade.

## Como Executar
1. Certifique-se de ter o **.NET SDK** instalado ou utilize o **Visual Studio / VS Code**.
2. Baixe os arquivos deste repositório.
3. Execute o arquivo principal (`Program.cs`) pelo terminal com `dotnet run` ou diretamente pela sua IDE.
